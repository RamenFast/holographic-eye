## The 3 priority POLISH areas (stability + clarity — chosen per Ben's ask)

**P-1 · Render discipline & idle cost (stability).**
Dirty-flag canvas rendering (kills the 16% idle CPU), remove the banding
gradient (#1), one reserved bottom info lane (#2), scrollbar gutter (#8).
Acceptance: idle CPU <1% with the window open; no overlapping text at any
pane/window size; tab switches don't shift content.

**P-2 · Affordance truthfulness (clarity).**
Every clickable element visibly does what it suggests: multi-entity highlight
as a real set (#3), chevron discloses or dies (#4), lens toggles predictably
(#6). Acceptance: click every interactive element in the app once — zero
no-ops, zero surprises.

**P-3 · One manual, honest settings (clarity / long-term sustainability).**
Single source of truth for legend+glossary (the ? manual); ⚙ holds only real
settings, each explained in one plain sentence (#5, #12; font-size #11 and
flowers toggle #9 live there when built). Keep GUI docs and README from
drifting by treating the glossary as the one canonical copy.
